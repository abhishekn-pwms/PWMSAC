Export

All 28 tables, every time — no partial exports. Downloads a snapshot of live data as it stands right now. CSV export also includes the actual attachment files from Storage; JSON export is metadata only.

Push to pwms_prev

Full-replace: deletes everything currently in pwms_prev, then inserts a fresh copy of live data. This is the actual disaster-recovery mechanism — a genuine second copy of your data on a separate Supabase project.

pwms_prev is locked to one dedicated backup login. Type its password below — it is used once for this push and never stored.

Verify backup

Reads everything in pwms_prev and everything in live, and compares them table by table and file by file. It only reads: nothing is changed on either side. Run it after each push, so you know the backup is good before you ever need it.

Restore from pwms_prev

Only for recovery. Replaces ALL live data and files with the copy in pwms_prev, so anything you changed after the last push is lost. Before it changes anything it downloads a complete copy of what live holds now, and it stops if that can't be saved. It never changes pwms_prev.

It refuses on its own if the backup is empty or incomplete. Run Verify backup first, and if it fails partway just run it again: it is safe to repeat.
